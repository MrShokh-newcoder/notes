> When a learner can't produce /ʒ/ (casual, usually), first diagnose whether it's one word or the sound in general. If general, start from a sound they already have (/ʃ/) and add voicing; with advanced learners the real problem is often speed.

## Procedure (B2+ adults)
1. Diagnose: other /ʒ/ words fine? Transfer what works to the problem word.
2. If general: produce /ʃ/, then add voice → /ʒ/.
3. Build voicing awareness with /s/–/z/ (hand on throat), then return to /ʃ/–/ʒ/ and place of articulation.
4. Exaggerate friction (head and fist movements). For some words, substitute /ʃ/ first, then voice it.
5. Slow down: speed hides the sound. Use spelled pronunciation (*KA-zhu-wul*) if IPA isn't known.
6. Practise in words → phrases → discussion questions → short text read aloud.

## Phonetics note *(Claude)*
/ʃ/–/ʒ/ is a voicing pair with the same place and manner, so this is the classic "known sound as anchor" technique (Underhill's *Sound Foundations* builds whole chart work on it). For Uzbek speakers /ʒ/ exists (*jurnal*), so the problem is usually spelling-to-sound (*-sual*, *-sure*), not articulation.

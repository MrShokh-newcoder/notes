> Paper 2 covers testing, materials and methodology: judge a test by its consequences for the learner, phrase material purposes as 'To + infinitive', and answer the methodology question in many short, theory-linked bullet points.

> [!warning] 2012 format
> Written by a long-serving Cambridge Diploma tutor and assessor, but for the 2012 exam. Mark allocations, task numbers and timings must be checked against the current *Delta Handbook for Tutors and Candidates*. Numbering already conflicts with [[DELTA Module 1 Paper 1 - packaging answers for the marker|Pinard (2013)]].

## Evaluating a test ([Part 5](https://eltnotebook.blogspot.com/2012/06/doing-delta-module-one-some-exam-tips.html))
- Start from the learner's consequences: can they do it? What happens to their placement and motivation?
- Each point: feature → helps or harms → effect on this learner.
- Concepts: face / content / construct / predictive **validity**, **reliability** (an impressionistic mark is unreliable), **backwash**, direct vs indirect tests, **fresh starts** (one task samples too narrowly).
- Her mnemonic "A little fat cat in Malfi" lists 18 checks (Administration, Level, Instructions, Test type, Length…).

## Analysing coursebook materials ([Part 6](https://eltnotebook.blogspot.com/2012/06/doing-delta-module-one-some-exam-tips_02.html))
- Purposes as "To + infinitive", each linked to the stated aim. If you can't phrase it that way, it's probably off target.
- Discuss only the activities the question names.
- Combinations: prepares for / extends / consolidates / balances.
- Assumptions about learning: state the assumption + one reason + the activity. Don't evaluate it.

## The methodology question ([Part 7](https://eltnotebook.blogspot.com/2012/06/doing-delta-module-one-some-exam-tips_05.html))
- ~15 short points (2 marks each), plus depth marks for theory and research.
- Link belief → practice → teacher role (guided discovery: discovered rules are retained better → teacher as facilitator).
- Suitability checklist: L1 groups, age, learner preferences, intensity, ESP, mixed ability, class size.
- Name theories: structuralism, functional-notional, lexical approach, behaviourism, cognitive code, input-based acquisition, noticing, constructivism. Krashen, Vygotsky, Maslow, Lenneberg, Gardner.

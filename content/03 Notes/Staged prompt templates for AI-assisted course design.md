> Plan skills like critical thinking deliberately across a course. A reusable prompt with placeholders (hours, weeks, learners, CEFR level) turns an LLM into a syllabus-design assistant whose output the teacher checks and edits.

## Template pattern
- Role: "Act as an expert in critical thinking / instructional designer for PBL."
- Placeholders: weekly hours · number of weeks · learner description · topic · CEFR level.
- Constraint: "focus on activities with the most impact on learners' abilities."
- Follow-up in the same chat: generate the actual materials.
- Check and edit every output.

## PBL version ([2024](https://peacheypublications.com/unlocking-the-power-of-project-based-learning-in-elt-challenges-benefits-and-ai-solutions))
Ask for a project built on the 7 **Gold Standard PBL** design elements (PBLWorks), with teacher instructions, then a rubric (pass / strong pass / fail). Barriers to PBL in ELT: coursebooks, little training, lesson-length thinking, assessment, workload.

## Limits
- Each post ends by promoting the author's paid books or courses; no evidence of learning outcomes.
- Doesn't address hallucination, or how a group rubric fairly assesses individuals.

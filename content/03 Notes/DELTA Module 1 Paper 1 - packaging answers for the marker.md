> Module 1 tests what you know, and also how well you package it in a marker-friendly way. Learn the guideline-answer formula for each task.

> [!warning] 2013 DELTA format
> Written as a candidate in 2013. Word counts, task numbers and handbook page references have changed since. Keep the method and check the details in the current Cambridge handbook.

## Task technique (2013 numbering)
- Terminology: give **one** term per definition. A double answer with one wrong term scores zero.
- Defining terms: definition + a further point + an example. Each element earns a mark.
- Text/genre features: predict the features from the rubric *before* reading. Her mnemonic **CLOGS** = Content, Layout, Organisation, Grammar/Lexis, Style.
- Learner-text analysis: separate sheets for Strengths and Weaknesses. When prioritising a weakness, give three reasons in the examiner's formula.
- Do timed past papers; start with the task you find least stressful; bullets, not prose.

## Resources named
Thornbury, *An A–Z of ELT* (terminology); Sandy Millin's Delta Quizlet collection; Cambridge examiner reports and guideline answers.

## Limits
- Task numbering differs between sources: Pinard (2013) puts genre analysis in Task 4 and learner text in Task 5, while Swift (2012) has the reverse. See [[DELTA Module 1 Paper 1 - task-by-task technique]]. The paper has changed more than once.

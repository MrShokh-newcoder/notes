> EPI isn't 'sentence builders'. A unit runs modelling → intensive receptive processing (90–95% comprehensible) → forced output → intensive retrieval that weans learners off the builder → optional grammar → planned then unplanned fluency, with recycling across units.

## The seven phases
1. Model target chunks (sentence builders, parallel texts).
2. Receptive processing: ~2 lessons of listening/reading flooded with the chunks until receptive mastery.
3. Forced output: highly structured tasks recycling new + old chunks (read-aloud games for decoding only).
4. Intensive retrieval (≥1 lesson): oral translation games (*No snakes no ladders*, *Oral ping-pong*), drills, structured tasks.
5. Optional, highly controlled grammar (needed more for inflected languages).
6. Fluency: planned tasks with task repetition (Bygate 2009, 2015), then unplanned tasks.
7. Recycle via the "Conti matrix" in later sub-units.
- Warning: a few Quizlet/Kahoot tasks a day is not EPI.

## Later framing ([2026](https://gianfrancoconti.com/2026/10/19/how-epi-aligns-with-rosenshines-10-principles-of-instruction/))
Conti maps each of Rosenshine's ten principles onto MARS EARS stages; he notes this is conceptual alignment, not validation.

## Critique *(Claude)*
No outcome studies of EPI as a package; Jordan calls the sentence-builder phase a synthetic syllabus in disguise. Its strongest components (input flooding, retrieval, task repetition) each have independent support.

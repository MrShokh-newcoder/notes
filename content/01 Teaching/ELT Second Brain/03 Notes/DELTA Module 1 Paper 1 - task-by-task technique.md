> Budget about one mark per minute, write semi-notes not essays, read the rubric literally, and give a specific example for every point. No example, no mark.

> [!warning] 2012 format
> Written by a long-serving Cambridge Diploma tutor and assessor, but for the 2012 exam. Mark allocations, task numbers and timings must be checked against the current *Delta Handbook for Tutors and Candidates*. Numbering already conflicts with [[DELTA Module 1 Paper 1 - packaging answers for the marker|Pinard (2013)]].

## Tasks 1–2: terminology ([Part 1](https://eltnotebook.blogspot.com/2012/04/only-two-months-to-go-to-next-cambridge.html))
- Exact term, one per definition; name the general concept ("an affricate"), not the example.
- Defining: a clear definition (2 marks) + one example (1). Don't just rephrase the term.
- Leave gaps and return to them. Make term/definition/example cards; drill on Quizlet.

## Task 3: subskills or language features for an activity ([Part 2](https://eltnotebook.blogspot.com/2012/04/doing-delta-module-one-some-exam-tips.html))
- "Feature: example" layout; exactly three points.
- Mix categories (one discourse, one structural/functional, one lexical) to avoid overlap.
- Level check: would a B1 learner actually use "I wonder if you'd mind…"? If not, it fails.
- Don't split one area (requests) into several points; don't repeat points.

## Learner text: strengths and weaknesses ([Part 3](https://eltnotebook.blogspot.com/2012/04/doing-delta-module-one-some-exam-tips_21.html))
- Use only the rubric's categories (task achievement, organisation/cohesion, register, lexis, grammar, spelling/punctuation, pronunciation).
- "Key" = recurrent, not a single slip.
- Layout: category → specific feature → text example ("/θ/ → /s/, e.g. /sʌndə/").
- Justify the priority weakness by its effect on communication.

## Genre and language analysis ([Part 4](https://eltnotebook.blogspot.com/2012/04/doing-delta-module-one-some-exam-tips_17.html))
- Genre features need a description + a quoted example.
- Analyse only the categories the rubric names (form / meaning / use / pronunciation / learner problems).
- Form: word class, tense, aspect, voice, affix spelling. Pronunciation: phonemic citation form, then connected speech. No phonemic script, no mark.
- Use: syntactic, semantic, stylistic, discourse (e.g. given–new).
- Daily 10-minute language-analysis drill. Books: Lewis, *The English Verb*; Thornbury, *About Language*; McCarthy, *Discourse Analysis for Language Teachers*; Carter & McCarthy, *Cambridge Grammar of English*.
